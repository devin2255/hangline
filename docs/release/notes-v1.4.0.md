# Hangline 1.4.0 — 晾衣绳，有了质感

这个版本只做一件事：把「晾衣绳」从一条固定的线，变成**可以换装、会随截图数量呼吸的绳子**。

## 新增

- **四种绳子材质**（托盘 → 外观 → 绳子样式）：
  - **真丝**：缎面渐变，一条干净的上缘高光；
  - **亚麻**：天然纤维的哑光捻线；
  - **黄铜链**：分段古铜链，暖金反光；
  - **暮光线**：柔光晕 + 细亮核（深色主题最有氛围）。
- **八种低饱和颜色**（托盘 → 外观 → 绳子颜色）：墨、象牙、香槟金、雾灰、鼠尾草、雾霾蓝、赤陶、烟紫。深浅主题自动适配，卡片挂针与挂环同步同色系。
- **绳子会随数量变弯**：空线接近平直（12dp），每多挂一张就再弯一点，12 张满绳 50.4dp；新截图落绳时弧度 220ms 缓动，卡片跟着"压"下去；系统开启「减少动态效果」时瞬时完成。
- **设置即时生效并记忆**：选完立刻换装，写入配置，重启保留；旧配置文件自动补默认（真丝 · 墨），无需迁移。

## 细节与克制

- 单一光源：每条绳子只有一条高光、一层阴影，不叠加花哨效果；两端渐隐，不出硬边；
- 60fps：绳子是静态 SVG，只有切换和落绳时做 180 / 220ms 过渡；
- 不变的部分：窗口数量、面板几何、点击穿透、拖拽、标注、搜索全部照旧。

- 真机截图：四种材质 × 深/浅主题、八色示例、0/3/满卡三档弧度（见发布附件与仓库文档）；
