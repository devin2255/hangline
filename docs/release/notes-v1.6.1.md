# Hangline 1.6.1 — 边框 → 毛衣，七种节日绳子

这一版把两个设置改得更直接，并把节日主题从「只有圣诞」扩展成可手动切换的七种。

## 边框：无 / 毛衣

不再单独出现「毛衣季」开关。托盘 → 外观 → **边框**：

- **无**：卡片保持原来的玻璃边框；
- **毛衣**：启用针织边框，宽度（细/经典/粗）和配色（自动/松林/霜白/浆果）仍在同一级菜单里；
- 悬停卡片的毛线球按钮继续支持 **换一件 / 锁定 / 脱掉**，每张卡的选择持久保存。

截图文件、卡片尺寸、绳子几何、点击穿透命中区都不变。

## 节日绳子：七种主题 + 手动切换

托盘 → 外观 → **节日绳子**：

**关闭 / 自动 / 元旦 / 春节 / 情人节 / 中秋 / 国庆 / 万圣节 / 圣诞**

- **手动**：选中任一主题随时预览，不受日期限制；
- **自动**：按本地日期窗口选择——
  - 元旦 12/30–01/02
  - 春节 除夕–正月初六（内置 2023–2036 农历表）
  - 情人节 02/12–02/15
  - 中秋 八月十四–十六（内置农历表）
  - 国庆 09/30–10/07
  - 万圣节 10/25–11/01
  - 圣诞 12/01–01/06
- 窗口重叠时优先更具体的节日（例如 12/31 显示元旦；春节与情人节重叠时显示春节）。
- 窗口结束后恢复你原来的绳子设置，不覆盖保存的材质/颜色。
- 七种主题各有独立绳色和挂饰：烟花/星星、灯笼、爱心、月亮/月饼、旗帜、南瓜/蝙蝠、松枝/彩球等。
- 系统「减少动态效果」时全部静止；窗口内主题仍关闭时，面板显示一次当季轻提示，指向托盘。

以上全部本地：不联网、不新增窗口、不改截图、不加遥测。
