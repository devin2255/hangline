# Hangline 1.6.3 — 节日绳子第二次打磨：更小、更金属、更克制

1.6.2 把节日绳子从「平铺图标」做成了花环；这一版按反馈继续收：**不卡通、不要大挂件、更高级。**

## 变化

- **装饰改成小尺寸金属挂件。** 七种主题分别使用黄铜、香槟金、玫瑰金、紫铜等单一金属色的小挂件
  （灯笼、爱心、星星、月亮、南瓜、蝙蝠等），带金属受光渐变和很轻的投影；尺寸比 1.6.2 再缩小约 40%。
- **不再用糖果色图标。** 挂饰和绳上的小花饰统一为同主题金属色，主题靠绳色、金属色和形状区分，
  而不是靠一块块彩色的卡通图形。
- **收尾更小。** 两端改成小黄铜绳帽 + 两根细丝带尾，不再是大蝴蝶结。
- **更安静的灯与氛围。** 灯串改成细小的暖光点；去掉大颗粒的呼吸微粒和大部分氛围光斑。
- **行为完全不变。** 仍是关闭 / 自动 + 七个手动主题；本地日期自动窗口、结束恢复原绳、默认关闭、
  不联网、不新增窗口、不改截图、不改变卡片命中区。减少动态效果时全部静止。
