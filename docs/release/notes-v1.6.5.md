# Hangline 1.6.5 — 节日挂饰改成垂下来的小件

1.6.3 把节日挂饰收成同一块金色。这一版把它们画回各自的样子，并让它们真正挂在绳上。

## 变化

- **每种挂饰用自己的颜色。** 红灯笼、粉心、月牙、南瓜、彩旗可以分开认出来。黄铜只做挂钩、帽口和绳结。
- **吊线接到顶部。** 挂饰从绳上垂下来，不再穿在图形中间。
- **绳子更安静。** 绳芯收细，金线改成细闪，灯点缩小，两端改成细丝带尾。
- **行为不变。** 关闭 / 自动 + 七个手动主题。不联网、不新增窗口、不改截图、不改点击命中区。

## 验证

- 七种主题的绳子按真实 SVG 成帧核对。
- 前端 340 项测试通过，其中包括节日日期。安装包仍受 8.5 MB 体积门约束，由 tag 工作流签名并发布。
