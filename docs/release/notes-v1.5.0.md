# Hangline 1.5.0 — 图片，直接拖上绳

这个版本只做一件事：**把图片从任何地方拖到屏幕上沿，挂到晾衣绳上。**

## 怎么用

1. 从**文件夹 / 微信或 QQ 聊天窗 / 浏览器 / 截图工具**按住一张图片开始拖；
2. 拖到**屏幕顶部**（不用先找绳子）：绳子会自动滑出来；
3. 把图片拖到绳线区域，绳子会亮起并提示"松手挂上绳子"——松手，卡片就挂上了。

不用先按热键、不用先截图；拖拽取消或拖去别处，绳子会照常收起。

## 细节

- **复制入库**：图片会复制进 Hangline 自己的目录（`Screenshots\Dropped …png`），源文件/微信临时文件删掉后卡片仍然可用；
- **按内容去重**：同一张图重复拖入不会挂第二张（跨重启也有效），右下角会提示"已在绳上"；
- **支持来源**：文件夹/Explorer 多图（一次最多 20 张）、微信/QQ 位图、浏览器图片、截图工具；视频和其他文件会提示"仅支持图片"；
- **新卡片可继续操作**：标注、右键菜单、拖去微信/文件夹、移入回收站（它属于 Hangline 自有文件）；
- **不打扰桌面**：普通点击/悬停照旧穿透；只有拖拽经过绳线时才会临时接管鼠标，松手立即恢复；
- **不新增窗口、不抢焦点、不联网**：仍然只有更新检查这一条网络请求。

## 已知限制

- 只接受**图片**（视频/文档/音频不支持）；
- 一次拖拽最多 20 张图片，单张 ≤64 MB / ≤80 MP，超出部分会提示不支持；
- 拖拽必须经过屏幕顶部唤出带（当前显示器工作区顶部 14 dp）才会自动唤出绳子；也可以先按 `Ctrl+Alt+T` 显示绳子再拖。
