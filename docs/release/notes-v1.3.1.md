# Hangline 1.3.1 — 拖拽修复

这是一个小的修复版本，只解决一个问题：**从晾图绳把卡片拖到其它应用（微信、资源管理器、桌面等）时没有反应。**

## 修复内容

- **根因**：拖出功能使用的 Windows OLE 拖拽模态循环跑在一个独立工作线程上。该线程收不到系统鼠标消息（日志里 8 秒内只收到 1 次 `QueryContinueDrag`、0 次 `GiveFeedback`），看门狗每次都把拖拽取消。
- **修复**：把拖拽排期到**面板窗口所属的 Tauri UI 线程**上执行（`DoDragDrop` 本身就是模态循环，会持续泵窗口消息，结束后事件循环立即恢复）。
- **真机验证**（Windows 11，v1.3.1 发布构建）：
  - 拖拽过程中 `QueryContinueDrag 44–47 次、GiveFeedback 44–46 次`（修复前 1 次 / 0 次）；
  - 拖到资源管理器文件夹：`DROPEFFECT_COPY`，文件被复制、源文件保留、卡片不消失；
  - 拖到微信聊天框上方：微信显示"复制"光标并返回拖拽反馈（目标接受），Esc 取消不发送。
- **使用方式**：按住卡片拖动超过 4 dp 即开始原生文件拖拽；拖到目标后松开。单击仍是复制、长按 0.45 s 仍是标注编辑器。

## 升级说明

- **数据兼容**：直接覆盖安装，旧 `settings.json` / `state.json` 可读，无需迁移。
- **未签名**：本版本仍未做 Authenticode 签名，SmartScreen 可能提示"未知发布者"；请用发布附件里的 `SHA256SUMS.txt` 校验。
- **已知限制**（同 1.3.0）：OCR 为本地 PoC（小字/短文本可能漏识）；停悬预览受面板高度限制；托盘菜单项级自动化测试未覆盖。

**校验**：附件中的 `SHA256SUMS.txt` 包含安装包、便携版与 `latest.json` 的哈希；更新清单由 CI 使用更新签名密钥签名。
