# Hangline 1.6.2 — 节日绳子视觉重做

不是加功能，是把节日绳子的「好看」补上。

## 变化

- **更结实的编织绳。** 绳芯改成深色渐变 + 外侧柔光 + 顶部高光 + 金色编织细线 + 更明显的阴影，不再是
  一条单薄的彩色线。
- **有体积感的挂饰。** 彩球、爱心、灯笼、南瓜、月亮等加入径向渐变受光、边缘暗部和投影；
  灯笼重画成圆润的灯笼形（金口、竖棱、流苏），春节不再像挂了一排小盒子。
- **主题花饰上绳。** 每个主题在绳上加入细小的主题元素：圣诞松枝/雪花、春节梅花/金结、中秋花瓣/星、
  国庆旗幡/星、万圣小蝙蝠/叶、情人节叶片/心、元旦/国庆的金色闪光。
- **更克制的收尾。** 两头改成细丝带结 + 自然垂下的丝带尾，不再是大块红色蝴蝶结。
- **暖光与氛围。** 灯串改成更大的暖色光晕；绳后增加极淡的氛围光斑和缓慢呼吸的微粒；
  七种主题各有独立的色温。
- **行为完全不变。** 仍是关闭 / 自动 + 七个手动主题；本地日期自动窗口、结束恢复原绳、默认关闭、
  不联网、不新增窗口、不改截图、不改变卡片命中区。系统「减少动态效果」时全部静止。
