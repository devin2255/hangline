# Hangline 1.6.4 — 毛衣边框改成平针

1.6.0 的毛衣边框是平涂图案。这一版按针织边框的织法重画：**能看见一针一线。**

## 变化

- **每一针是两股圆毛线。** 底下有投影，外圈压暗，中间是毛线本色，上肩有一道同色高光。针与针之间露出压暗的底纱，上面再撒一点散纤维。
- **图案画在针脚上。** 格纹、人字、条纹、雪花、费尔岛仍按卡片 id 稳定选择；颜色仍是截图取样，或松林 / 霜白 / 浆果。
- **边框加宽。** 细 12 dp、标准 15 dp、粗 20 dp（原先 6 / 9 / 12），这样才能放下两到三行能看清的针。
- **行为不变。** 边框仍是「无 / 毛衣」，默认关闭。不改截图、不改卡片尺寸、不改绳子、不改点击命中区，不联网、不新增窗口。

## 验证

- 五种图案的边框在浏览器里按真实 SVG 成帧核对。
- 前端 340 / Rust 库 423 / 二进制 33 测试通过。安装包仍受 8.5 MB 体积门约束，由 tag 工作流签名并发布。
