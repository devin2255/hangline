# Hangline 1.5.1 — 托盘里就能看到当前版本号

一个小更新：托盘菜单里的「**检查更新…**」现在会直接显示你当前安装的版本。

## 变化

- 打开托盘菜单，更新项会显示为 **「检查更新…（v1.5.1）」**（英文 `Check for updates… (v1.5.1)`）；
- 点击后照旧执行手动检查；自动更新逻辑、签名校验、24 小时检查间隔都没有变化；
- 以后想知道自己装的是哪一版，不用翻安装目录或发布页，右键托盘看一眼即可。

## 为什么做

此前托盘只显示「检查更新…」，用户点之前无法确认自己运行的是哪一版；1.5.1 把版本号放到同一行，既不多占菜单项，也方便反馈问题时直接报出版本。

## 验证

- 新增中英文标签单元测试（固定断言 `Check for updates… (vX.Y.Z)` / `检查更新…（vX.Y.Z）`）；
- 托盘刷新时与其它动态菜单项一样重新应用该文案；
- 全量测试、体积门、`--selftest` 与 CI 结果见发布页 / `docs/product` 验收记录。
