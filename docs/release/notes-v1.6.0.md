# Hangline 1.6.0 — 毛衣季 + 圣诞绳

**绳上的截图，也过冬了。**

1.6.0 给每条绳子加了两件「冬装」：**毛衣季**——每张截图自动套上一圈由它自己取色的针织边框；以及**圣诞绳子**——松绿金线、灯串、彩球、铃铛、雪花与松枝。

两件事都默认关闭，在托盘 → **外观** 里开启；都不联网、不新增窗口、不改动你的截图文件。

## 毛衣季（默认关闭）

- **截图自己配色。** 本地从缩略图取主色，降饱和、提亮后得到 3 个毛线色：主色、对比色、中性色。取不到颜色（灰度图、损坏缩略图）时按卡片 id 稳定回退，不会出现空边框。
- **图案稳定。** 5 种原创针织图案：锯齿（chevron）、格纹（checks）、雪花（snowflake）、条纹（stripe）、费尔岛（fairisle）；同一张卡每次打开都是同一件。
- **3 档宽度**：细 6dp / 经典 9dp / 粗 12dp。
- **4 套配色**：自动（取自截图）/ 松林 / 霜白 / 浆果。
- **每张卡可换装。** 悬停卡片，点胶囊里的毛线球按钮：
  - **换一件**：按顺序换下一种针织图案；
  - **锁定 / 解锁**：记下当前样子（换图案或换配色后仍保留自己的设置）；
  - **脱掉 / 穿上**：只让这一张卡不穿毛衣，不影响整条线。
  选择写进 `state.json` 的卡片字段，重启后仍然有效。
- **不改图。** 边框是卡片上的纯 SVG 装饰层：截图文件、卡片尺寸、绳子几何、点击穿透命中区都不变。

## 圣诞绳（默认关闭）

- 托盘 → 外观 → **节日绳子**：关闭 / 自动 / 圣诞。
- **自动**按本地日期生效：**12 月 1 日 – 1 月 6 日**（含首尾）。窗口结束后自动恢复你原来的绳子材质和颜色，不会覆盖设置。
- 装饰全部是本地 SVG：松绿绳 + 金线、暖白灯串呼吸、彩球 / 铃铛 / 星星 / 雪花 / 松果轻摆、两端松枝和蝴蝶结。系统开启「减少动态效果」时全部静止。
- **圣诞** 是手动预览项：不在窗口内也能看效果；选回「自动/关闭」即恢复。
- 窗口内、主题仍关闭时，面板会显示**一次当季**的轻提示，指向托盘；提示只写本地 `localStorage`，不抢焦点、不弹窗。

## 隐私与边界

- 取色、日期判断、动画全部在本地；没有新增网络请求、没有新增窗口、没有遥测。
- 不修改截图文件；所有装饰都是卡片/绳子上的渲染层。
- 旧 `settings.json` / `state.json` 直接兼容：新字段缺省即关闭 / 自动。

## 验证

- 前端 337 个测试、Rust 库 410 个测试、二进制 33 个测试全部通过；`pnpm check` 通过。
- 真机验证：debug 构建 + WebView2 DevTools 协议，在隔离的本地数据目录里用三张中性合成截图跑通：
  - 毛衣边框按截图取色、三种图案同时出现；
  - 毛线按钮 → 中文菜单「换一件毛衣 / 锁定毛衣 / 脱掉毛衣」；
  - 点击后 `state.json` 依次变为 `pattern=stripe`、`locked=true`、`enabled=false`；
  - 截图与菜单截图见 [功能文档](../product/2026-11-16-v1.6.0-sweater-season.md)。
- 安装包仍受 **8.5 MB** 硬体积门约束；`--selftest`、SHA-256、更新签名与 CI 结果随 Release 页核验。

## 已知说明

- 安装包目前仍未做 Authenticode 签名，SmartScreen 可能提示未知发布者；请用 `SHA256SUMS.txt` 校验。
- 毛衣取色来自缩略图，极低饱和的截图会得到接近灰白的毛线色——这是有意的「安静」默认，可在托盘里改用松林/霜白/浆果套装。
