# Hangline 1.3.0 — 截图记忆与检索

这是自 **v1.1.0** 之后的第一个发布版本，一次性包含 v1.1.1、v1.2.0、v1.3.0 三项迭代。一句话概括：**截图不只挂在绳上，现在还能备注、打标签、搜索、看大图——包括搜截图里的文字。**

---

## ✨ 新增功能

### 1.3.0 记忆与检索（Wave 2）

- **卡片备注与标签**：每张卡片都可以加纯文本备注（≤2000 字符）和最多 20 个标签（单个 ≤32 字符，自动去重）。旧 `state.json` 直接兼容，无需迁移。
- **搜索窗口（`Ctrl+Alt+F`）**：按需打开的小窗，边输入边过滤——**文件名 / 备注 / 标签 / 路径 / 截图里的文字**（本地 OCR）。支持 ↑/↓ 选择、Enter 复制并关闭、Esc 关闭、双击打开；在右侧详情区直接编辑备注与标签。
- **四个搜索入口**：全局热键 `Ctrl+Alt+F`（可改键，冲突检测/回滚与其他热键一致）、托盘「搜索…」、卡片右键菜单「Search…」、改键小窗。
- **停悬大图预览**：指针在卡片上停留 300 ms，原图在面板窗口内浮出（底部对齐、水平居中；受面板高度限制，录像不预览）；移开、滚动、拖动、打开菜单都会立即收起。
- **本地 OCR 文字索引（PoC 已通过闸门）**：使用 Windows 自带的 `Windows.Media.Ocr`，把截图内的文字索引到本地 `ocr-index.json`——**安装包 0 字节增量、完全离线、可随时删除重建**。在 30 张合成中文评测集上关键词召回 **81.67%**（98/120，平均 94.6 ms/图），搜索窗会把"图片文字"命中的结果标出来并显示上下文。

### 1.2.0 卡片操作面（Wave 1）

- **卡片右键菜单**：复制图片 / 复制为文件 / 打开 / 在资源管理器中显示 / 标注（录像为裁剪）/「取下线 ▸」（移入回收站、仅从线上移除、取下左侧全部、取下右侧全部）。菜单直接渲染在面板窗口内，不新增窗口、不抢焦点，菜单区域可正常点击。
- **悬浮动作胶囊**：悬停卡片下方浮出三个按钮（复制 / 标注或裁剪 / 更多）。
- **标注工具 5 → 9**：新增高亮、马赛克、模糊、自动递增序号；预览与导出共用同一渲染器。
- **编辑器分层回退**：Esc / 右键逐层退出（文字 → 裁剪 → 工具 → 放弃更改确认）。
- **截图完成动作可配置（托盘）**：可选"截图后自动复制"到剪贴板；若保存失败，裁剪图会兜底复制进剪贴板，不再丢图。
- **第三个全局热键**：`Ctrl+Alt+E`（默认）打开最新一张截图的标注编辑器（录像打开裁剪窗），托盘与改键小窗均已支持。
- **托盘可解释化**：保留策略子菜单增加"文件会被怎么处理"的说明行；「全部取下线」增加 Yes/No 确认框（含数量与文件语义，默认"否"）；全局热键注册失败会在启动时提示，不再静默失败。

### 1.1.1 可靠性与诊断（Wave 0）

- **`hangline.exe --selftest` 现场诊断**：10 项检查（数据目录可写、设置/状态完整性、磁盘空间、DPI、显示器、WebView2 运行时、内存、开机启动、版本），退出码 = 失败数，结果同时写入 `logs/selftest.log`。
- **设置/状态三层兜底**：保存时轮换 `.bak`，主文件损坏自动从备份恢复；文件存在但读取失败时**拒绝覆盖**并给出诊断，损坏样本保留为 `.corrupt`。
- **发布纪律**：安装包体积门从 15 MB 收紧到 **8.5 MB**，CI/脚本/文档使用同一门禁与四项体积报告。

## 🐛 修复

以下是本发布周期内发现并解决的问题（v1.1.0 用户不会再遇到）：

- **按住鼠标再按截图热键，框选会丢失**：热键触发时先按下的左键拖动现在会被完整接管（捕获 Chromium 子窗口 + Rust 光标采样事件驱动选区），松手即可完成截图。
- **截图保存失败会丢图**：保存失败时自动把裁剪图复制进剪贴板，并在日志中记录降级原因。
- **菜单/胶囊等浮层与点击穿透区不一致**：菜单、子菜单、悬浮胶囊都纳入点击命中区，菜单可点、外部点击关闭且不会误触发"复制图片"。
- **小面板下右键菜单可能超出面板被裁切**：新增按面板高度自适应压缩分隔线（行永不丢），small/medium/large 三档都完整可见可点。
- **热键注册失败没有任何提示**：现在启动时弹出一次说明（列出失败的快捷键与修改入口），托盘快捷键行同步标注。
- **设置或状态文件损坏可能被静默覆盖**：三层持久化兜底后，损坏文件可从 `.bak` 恢复，读不出的文件拒绝写入。
- **托盘危险操作没有确认**：「全部取下线」现在弹确认框（显示数量与"文件进回收站、监听目录不删除"的语义，默认"否"）。

## 🔧 改进

- **内存**：搜索窗按需创建、关闭即销毁，常驻内存不随使用增长；实测干净进程树常驻 **247.9 MB**，开窗峰值 **284.4 MB（+36.5）**，关窗 **252.2 MB（+4.3）**。
- **隐私不变**：OCR 全本地运行，不下载模型、不联网；唯一的网络请求仍然是更新检查。索引是一个纯本地 JSON 文件，删除后搜索自动降级为"文件名/备注/标签/路径"。
- **键盘可操作**：搜索窗支持全键盘操作（自动聚焦、↑/↓、Enter、Esc），索引状态行会显示"构建中 / 就绪 N / 本机不支持"。
- **质量数据**：前端 **303** 项测试、Rust **403 + 32** 项测试全部通过；安装包 7,466,233 B（8.5 MB 门禁的 87.84%），便携版 8,651,466 B；`--selftest` PASS 9 / FAIL 0。

## ⬆️ 升级说明

- **数据兼容**：直接覆盖安装即可。`settings.json` / `state.json` 旧格式可读（新增字段有默认值），**无需手动迁移**；搜索窗首次打开会在后台为已有截图建立文字索引（增量、最多每次 50 张），可随时删除 `%LOCALAPPDATA%\Hangline\ocr-index.json` 重建。
- **未签名说明**：本版本仍未做 Authenticode 代码签名，SmartScreen 可能提示"未知发布者"；请用发布附件里的 `SHA256SUMS.txt` 校验。我们正在申请 SignPath Foundation 的免费 OSS 签名（政策见 `CODE_SIGNING_POLICY.md`），通过后会更新。
- **已知限制**：
  - OCR 为本地 PoC：小字号/短文本、数字与中英混排、靠右的价格/时间可能漏识；每次打开搜索窗最多增量索引 50 张。
  - 停悬预览受面板高度限制，是大号预览而非全屏查看器；细节查看请用标注编辑器。
  - 托盘菜单项级自动化测试尚未覆盖（Win11 托盘溢出区限制），功能本身可用。

**校验**：附件中的 `SHA256SUMS.txt` 包含安装包、便携版与 `latest.json` 的哈希；更新清单 `latest.json` 由 CI 使用更新签名密钥签名。
