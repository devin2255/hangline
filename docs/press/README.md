# Hangline press kit

![Hangline logo](hangline-logo.png)

**Hangline (晾图绳)** — a Windows screenshot clothesline. Screenshots land on a thin line at the top
of the screen as glass cards; click to copy, double-click to open, drag out, long-press to mark up
or trim a recording, and click × to take it down.

- Platform: Windows 10 22H2 / 11 x64 (WebView2; installer bootstraps it when missing)
- License: MIT (app), see `LICENSE` and `THIRD_PARTY_NOTICES.md`; inspired by Tendedero (MIT with
  name/icon restriction), independent Windows implementation, original name/icon/art.
- Price: free / open source.
- Status: 1.0.0 source release; unsigned installer (SmartScreen may warn), no public download
  unless the operator publishes a GitHub Release.

**EN:** Hangline turns Windows screenshots into a clothesline at the top of your screen: capture,

no telemetry — update checks are the only network request.
