## 0. 一句话

**v1.4.0 把「晾衣绳」从固定装饰升级为可定制的记忆载体：4 种材质 × 8 种低饱和颜色，加上按线上可见卡片数动态变化的弧度——空绳近直、卡片越多越弯，最多 12 张时接近满弯。**

它不改产品骨架（单面板、不抢焦点、点击穿透、玻璃卡片、弹簧物理、60fps），只改「绳」这一条线的材质、颜色与几何曲线；**不新增窗口、不新增网络、不改面板尺寸**。

## 1. 设计概念：静奢（Quiet Luxury）

| 原则 | 在本功能中的含义 | 反例（不要做） |
|---|---|---|
| **单一光源** | 所有材质的高光/阴影都按「光从上方来」解释：上缘亮、下缘暗；渐变方向一致 | 把高光画在下缘、亮暗方向互相矛盾 |
| **低饱和** | 8 色全部为低饱和自然色（墨/象牙/香槟/雾灰/鼠尾草/雾霾蓝/赤陶/烟紫） | 高饱和荧光色、纯黑纯白大面积、彩虹渐变 |
| **材质对比** | 4 材质靠**纹理**区分（缎面/捻线/链节/柔光），不靠更亮的颜色 | 4 种材质只是同一条线换 4 个粗细 |
| **克制动效** | 只有两种动效：切换材质/颜色 180ms 过渡、卡片数变化时弧度 220ms 缓动 | 绳子常驻摆动/流光/呼吸循环 |

**与现有视觉体系的关系**（不引入新体系）：

- 沿用面板既有玻璃材质参数与卡片语言（`Panel.css` 的 `--glass-*` token、卡片圆角 16 dp、内衬 4 dp、夹子几何）。
- 绳子从「固定 sag 的装饰线」变成「随卡片数量呼吸的结构线」，但它仍然是**背景元素**：夹子（9×26 dp）与卡片（圆角、倾斜 ±2.5°）的视觉权重必须高于绳本身。
- 颜色只作用于绳与夹子的同色系微调（`--rope-palette`），**不改卡片内的照片/文字对比度**。

| 默认值 | `{"ropeStyle":"silk","ropeColor":"ink"}` |

| 符号 | 签名 / 语义 |
|---|---|
| `ROPE_SAG_BASE` | `12` |
| `ROPE_SAG_PER_CARD` | `3.2` |
| `ROPE_SAG_MAX` | `52` |
| `ROPE_WIDTH_REF` | `1600` |
| `ropeSag(panelWidth: number, visibleCards: number): number` | 见 §5 公式；返回值保留 2 位小数 |

## 3. 材质规格（4 种）

**共同结构**：`<defs>`（按 style 生成 gradient/filter，id 稳定）+ 3 层基础（shadow / core / highlight）+ style 专属层；层间只允许用 `opacity`/`stroke` 做 180ms 过渡。

| style | 中文 | Layer 结构 | 核心线 | 高光 | 纹理 / 特效 |
|---|---|---|---|---|---|
| `silk` | 真丝 | 缎面渐变 + 上缘高光 + 下方阴影 | **2.2 dp** | **0.7 dp**，不透明度 **0.85** | 沿曲线的水平渐变：`color → 提亮 18% → color`；阴影 2 dp |
| `linen` | 亚麻 | 核心 + 捻线纹理 + 低高光 | **2.8 dp** | **0.4 dp**，不透明度 **0.55** | `stroke-dasharray: 7 1.6`；叠一条 offset `1.6 7` 的低透明度纹理线（捻线感） |
| `brass` | 黄铜链 | 分段链节 + 暖金渐变 + 高光 | **2.6 dp** | **1.1 dp**，不透明度 **0.75** | `stroke-dasharray: 9 2.5`（圆头 `stroke-linecap:round`）；暖金渐变；`champagne` 时最明显，其它颜色按 `color` 提亮 10% 做暖调 |
| `aurora` | 暮光线 | 柔光 + 亮核（无阴影层语义） | **1.2 dp** 亮核 | —— | **5 dp** 低透明发光层（`feGaussianBlur stdDeviation≈1.6`）+ 双色渐变亮核（`color → color 提亮 25%`）；深色主题观感最佳 |

**渲染要求**

- 端点渐隐沿用现有 CSS mask；绳不得拦截鼠标（`pointer-events:none`）。
- `prefers-reduced-motion: reduce` 时关闭 180ms 过渡。
- 四材质在**深色/浅色主题**都要能区分：允许各主题下微调 `opacity`，但不允许改结构（核心/高光/纹理层数不变）。

## 4. 调色板（8 色 + 高光/阴影 + 主题自适应）

| key | 中文 | HEX | 气质说明 |
|---|---|---|---|
| `ink` | 墨 | `#1C1C1E` | 默认色；最接近现有深色绳，深色主题下需提亮才可见 |
| `ivory` | 象牙 | `#EFE9DD` | 浅色主题的安全选择；深色主题上偏亮 |
| `champagne` | 香槟金 | `#C8A96A` | 与 `brass` 材质最搭；唯一「暖金」锚点 |
| `fog` | 雾灰 | `#8E9196` | 中性、最不抢眼 |
| `sage` | 鼠尾草 | `#8A9A7B` | 自然绿，低饱和 |
| `haze` | 雾霾蓝 | `#7A8FA6` | 冷调中性 |
| `terracotta` | 赤陶 | `#B46A55` | 暖调点缀 |
| `violet` | 烟紫 | `#8B7B9B` | 冷调点缀 |

**高光 / 阴影**

| token | 值 | 用法 |
|---|---|---|
| 高光（标准） | `#FFFFFF` | 冷色材质的上缘高光 |
| 高光（暖色） | `#FFF6E8` | champagne / terracotta / brass 等暖色材质 |
| 阴影 | `rgba(0,0,0,.5)` | 绳下方阴影层（不透明度按材质 0.55–0.85 调整） |
| 深色主题自适应 tint | `#F4EFE6`（暖白） | 与调色板做 `color-mix` |

**主题自适应规则**

- 目标色统一计算：`color-mix(in srgb, var(--rope-palette) 62%, var(--rope-adaptive-tint))`；深色主题 `--rope-adaptive-tint: #F4EFE6`，浅色主题取同色或略深（保证浅底上不糊）。
- **对比度 ≥ 3:1**（绳的可见色 vs 面板背景/玻璃卡片邻近区域）；`ink` 在深色主题下必须提亮到可见（不得出现「黑绳消失在深色面板里」）。
- 夹子/绑带用 `--rope-palette` 做同色系微调（subtle），不得比卡片照片更抢眼。

## 5. 动态弧度模型（本版核心）

### 5.1 公式与常量

```
sag = clamp(12 + 3.2 × 可见卡片数, 12, 52) × min(1, max(0.45, 面板宽 / 1600))
```

| 常量 | 值 | 含义 |
|---|---|---|
| `ROPE_SAG_BASE` | `12` | 空绳基础垂度 |
| `ROPE_SAG_PER_CARD` | `3.2` | 每张可见卡片增加的垂度（dp） |
| `ROPE_SAG_MAX` | `52` | 垂度上限（防御性 clamp） |
| `ROPE_WIDTH_REF` | `1600` | 宽度归一化参考（dp）；窄面板按比例收缩，最低 0.45 倍 |

**参考值（面板宽 1920 dp，factor = min(1, 1920/1600) = 1）**

| 可见卡片数 | `clamp(12+3.2n)` | × width factor | `sag` |
|---|---|---|---|
| 0 | 12 | ×1.0 | **12.0** |
| 3 | 21.6 | ×1.0 | **21.6** |
| 12 | 50.4 | ×1.0 | **50.4** |

**窄面板（1280 dp，factor = 0.8）**：0 张 → **9.6**；3 张 → **17.28**；12 张 → **40.32**。
**极窄面板（≤720 dp，factor = 0.45 下限）**：12 张 → **22.68**。

> 说明：可见卡片上限 12（容量公式 `max(3, min(12, ...))`），因此正常使用中最大 sag = **50.4**（面板 ≥1600 dp 时）；`52` 是给「可见数 >12」的防御性上限，两者不要混写。文档/验收提到「12 张满弯」指 **50.4**。

### 5.2 曲线

- 二次贝塞尔，控制点 `ROPE_TOP + 2*sag`：`y(t) = ROPE_TOP + 4*sag*t*(1-t)`，中点下坠 = 完整 `sag`。
- `ROPE_TOP = 10 dp` **不变**；卡片/夹子挂接关系不变（见 §6 与 spec §3.3 原文）。
- 卡片 top 位置由 `cardTopFromRope(ropeY(line, ropeX, sag))` 计算；绳弯了卡片必须跟着下降。

### 5.3 动画

| 场景 | 时长 / 曲线 | 说明 |
|---|---|---|
| 卡片数变化（落绳/下线）→ sag 变化 | **220 ms**，`cubic-bezier(0.22, 1, 0.36, 1)` | rAF 插值当前 sag → 目标 sag；`prefers-reduced-motion: reduce` 时**瞬时跳变** |
| 切换材质 / 颜色 | **180 ms** | 只过渡 SVG `opacity`/`stroke`，不重排几何 |
| 首帧 | 0 ms | sag state 初值 = 目标值，**不允许首帧从 12 跳到目标值** |

### 5.4 面板容纳（硬约束）

- 卡片底边**不得超出面板高度**：small/medium/large 三档 × 12 张满弯（按该档最大 sag）都要满足。
- 面板高度档位（既有常量）：189 / 210 / 246 dp（small/medium/large）；绳 sag 增大只允许压缩绳下空白，不允许裁切卡片或改变面板高度。
- 在 `layout.test.ts` 增加「三档 × 12 张满弯时卡片底边 ≤ 面板高度」的断言；真机验收补三档截图。

## 7. 性能、无障碍与边界

**性能**

- 绳是 **SVG 静态渲染**：材质变换只切 `<defs>`/层 `opacity`，不重建 path；除 220ms sag 插值外**无逐帧工作**。
- `aurora` 的 `feGaussianBlur` 是静态滤镜（不逐帧重算），4K 宽度下也只在渲染时计算一次；若真机观察到拖影/掉帧，降级为「半透明宽线 + 亮核」不改变观感结构。
- 目标：12 卡 + 切换动画期间 60fps（沿用既有 60fps 验收方法：帧环/长帧统计）；新增窗口数为 **0**。
- 内存：只新增 DOM/SVG 节点与 CSS 变量，不新增 WebView2 窗口；**不改变进程树内存预算**（口径见 spec 内存 Amendment）。

**无障碍 / 降级**

- 绳对辅助技术不可见（`aria-hidden`）；信息不依赖颜色单一通道（4 材质用纹理区分，不只靠色相）。
- `prefers-reduced-motion: reduce`：sag 瞬时、材质过渡关闭；不影响功能。
- 高对比/色弱模式：保证绳与背景对比 ≥3:1；`ivory`/`champagne` 在浅色主题下需实测并微调 opacity/tint，不许「看不见还算上线」。
- 不改变「**唯一网络请求 = 更新检查**」：本功能纯本地渲染，无网络。

## 9. 风险与「不做」

| # | 风险 | 缓解 |
|---|---|---|
| R1 | **浅色在浅底上不可见**（ivory / champagne on light theme） | 统一走 `color-mix(..., 62%, tint)` + 实测 ≥3:1；必要时只对该色对提高 opacity/加深 tint，不改结构 |
| R2 | **12 张满弯导致卡片/夹子被面板裁切** | 三档 × 12 张的底边容纳测试前置；必要时只压缩 sag 上沿空白，不改面板高度/卡片尺寸 |
| R3 | **`aurora` 的 blur 在 4K 宽度掉帧** | 静态滤镜（不逐帧）；真机观察，超预算降级为「宽半透明线 + 亮核」 |
| R4 | **枚举增长导致前后端/托盘/i18n 漂移** | §2 契约表作为唯一来源；新增枚举必须同时改 Rust enum、TS 联合类型、托盘 ID、`TrayStrings`、测试 |
| R5 | **旧配置未知值**（手改 `settings.json`） | 与 `CardSize` 同口径**拒绝**并给出可诊断错误，不静默改写用户文件 |
| R6 | 视觉权重喧宾夺主 | 绳保持背景元素：夹子/卡片优先；材质靠纹理不靠亮度；验收含「绳不抢卡片」主观复核 |

**不做（本版边界）**

- **不做任意取色**（无 color picker、无自定义 hex 输入）——8 色为受控调色板。
- **不做绳子常驻动画**（无循环摆动/流光/呼吸；只有 sag 变化与切换过渡）。
- **不改面板几何/窗口数量/卡片尺寸**；不新增窗口；不引入新依赖；不改网络行为。
- **不做绳子上的额外装饰**（挂饰/文字/图案）——绳子只是材质与曲线。
