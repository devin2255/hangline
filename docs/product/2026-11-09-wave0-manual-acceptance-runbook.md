## 1. 块 A：安装、首次启动、托盘与热键（对应步骤 1/2/4/5，M1）

- [ ] **A1 冷启动计时**：双击 `hangline.exe`（或安装后从开始菜单启动），用秒表/手机计时到**托盘图标出现**；再按 `Ctrl+Alt+T` 计时到**线滑下可见**。
  - 期望：托盘出现 ≤3 s；线可操作；首帧**无白闪/黑底**；任务栏**无窗口按钮**。
  - 记录：托盘出现 ___ ms；线可见 ___ ms；白闪：有/无（颜色____）。
- [ ] **A2 真实物理热键**：按 `Ctrl+Alt+T` 两次（隐藏/显示）；按 `Ctrl+Alt+S` 框选一小块松开（应上栏）；再按 `Ctrl+Alt+S` 后按 `Esc`（应取消，不产生文件/卡片）。
  - 期望：全部响应；`Esc` 取消干净（数据目录不新增 PNG、线上不新增卡片）。
  - 记录：是否响应；与哪些程序冲突；取消后新增文件数____。
- [ ] **A3 托盘**：左键单击托盘图标（应切换线）；右键逐项浏览菜单；**Language → English** 再切回**简体中文**；点一次「显示线/隐藏线」；双击托盘图标。
  - 期望：菜单完整（显示线、全部取下线、截图、3 个来源勾选、线出现方式、也监听文件夹、保留数量、尺寸、快捷键、打开截图文件夹、声音、开机启动、检查更新、语言、退出）；切语言后**托盘菜单与面板文案同时变化**；双击为两次 toggle（净效果不变，属已知行为）。
  - 记录：缺失菜单项____；语言切换是否同时生效；托盘是否在溢出区。
- [ ] **A4 点击穿透**：点击线两侧透明区的桌面图标/浏览器链接；再点击卡片。
  - 期望：透明区点击落到下层应用；卡片可按下；前台窗口**不会变成 Hangline**；不抢焦点。
  - 记录：是否有点击被吃掉；前台是否被抢。

- [ ] **A5 首次启动引导**（若产品有引导页/首次提示）：确认文案真实、可关闭、不再重复弹。

## 2. 块 B：四条采集链路（对应步骤 4/7/8，M5/M6）

- [ ] **B1 自有截图**：`Ctrl+Alt+S` 截一块有明显内容的区域 → 卡片上栏，内容正确。
- [ ] **B2 系统截图目录**：`Win+PrtScn` 截一张 → 只上**一条**卡片，不重复。
- [ ] **B3 Win+Shift+S（仅复制）**：截一张不保存 → 剪贴板链路上栏**一条**。
- [ ] **B4 Win+Shift+S（自动保存开启）**：先在截图工具设置里开启自动保存 → 再截一张 → **只上一条**（目录 + 剪贴板双链路去重生效）。
- [ ] **B5 真实应用复制**：在微信/QQ 里复制一张图片 → 上栏；在 Excel 复制单图/区域 → 上栏；复制**一段纯文本** → **不应**上栏；浏览器「复制图片」（带 HTML）→ 按设计**不应**上栏。
- [ ] **B6 Game Bar**：`Win+Alt+R` 录 5 秒并停止 → 录屏卡片上栏，显示首帧 + 播放角标。
  - 期望：B1–B6 无重复、无缺失、卡片内容/类型正确。
  - 记录：每项产生几条卡片；异常应用名 + 复制方式。

## 3. 块 C：卡片动作与拖拽语义（对应步骤 6/9/10/11，M8/M9/M10/M11）

- [ ] **C1 单击复制 → 真实粘贴**：单击卡片（等约 0.5 s，出现「Copied/已复制」）→ 到微信/浏览器 `Ctrl+V`。
  - 期望：粘贴出**图片**（不是文件、不是路径文本）；卡片弹胶囊 1.2 s。
- [ ] **C2 双击**：双击卡片 → 默认应用打开；**剪贴板内容不变**（先复制一段已知文本到剪贴板，双击后粘贴应仍是那段文本）。
- [ ] **C3 拖到应用**：把卡片拖到微信/Figma/浏览器（任选能接收文件的应用）松开。
  - 期望：出现系统拖拽光标；目标收到图片/文件；**卡片保留在线上**。
- [ ] **C4 拖到文件夹/桌面**：拖到空文件夹松开；再拖一张到桌面松开。
  - 期望：文件出现在目标、原路径消失；卡片约 0.6–2.6 s 内掉落。
- [ ] **C5 拖到回收站**：拖到回收站图标松开 → 文件可在回收站**还原**、卡片掉落。
- [ ] **C6 取消拖拽**：再拖一次，拖出线外按 `Esc` → 无文件变化、卡片复位、可再次拖拽。
- [ ] **C7 取下线（×）与撤销**：点 × 下线自有截图 → 在回收站还原该文件 → 记录行为是否符合「自有截图进回收站，监听目录文件只下线」。
- [ ] **C8 150% 副屏拖拽**：把鼠标移到 150% 副屏等线迁移后，拖一张卡片到该屏文件夹 → 光标与投递正常。

  - 记录：粘贴结果（图片/文件/无）；每项是否卡在按下态；掉落耗时；回收站可还原与否。

## 4. 块 D：文件夹监听、多屏跟随、容量与持久化（步骤 12/13/14，M14/M16）

- [ ] **D1 添加监听文件夹**：托盘 → 也监听文件夹 → 添加文件夹… → 选一个有 PNG 的文件夹 → 往里面复制一张新 PNG → 应上栏（类型=监听目录）。再点一次添加并**取消** → 设置不变。加到 3 个后「添加文件夹…」应变灰。
- [ ] **D2 多屏跟随与跨接缝框选**：鼠标移到 150% 副屏停留 1–2 s → 线迁移；在副屏框选（最好横跨 x=0 接缝）→ 截图内容与尺寸正确、无错位。
- [ ] **D3 容量与滚动**：托盘 → 保留数量 → 100；用 `Ctrl+Alt+S` 连截 12 张以上；滚轮/触控板前后滚动 → 最新在右、无卡顿。
- [ ] **D4 退出与重启持久化**：托盘 → Quit Hangline → 任务管理器确认无残留进程；重启应用 → 设置（保留数量/尺寸/语言）保留；删除一张自有截图文件后重启 → 该卡片消失、其余恢复。
- [ ] **D5 全屏抑制**：打开全屏视频/游戏（或 F11 全屏网页）→ 线自动隐藏；退出全屏 1 s 内恢复。

## 7. 已知会「失败」或「反常」的项（先看这里，避免误报）

| 现象 | 归属 | 处理 |
|---|---|---|
| `Win+Shift+S` 后剪贴板没上栏 | 若系统未把图放进剪贴板 / 或复制带文本 | 属设计过滤，记 SKIP 并注明 |
| 浏览器「复制图片」不上栏 | 带 HTML/文本，按设计拒收 | 记 SKIP（设计如此） |
| 只提供 `CF_BITMAP` 的旧应用复制不上栏 | V1.1 评估项 | 记 SKIP |
| HEIC 只显示文件名占位 | 无解码器 | 记 SKIP |
| 锁屏/远程桌面下热键无效 | OS 行为 | 必须解锁桌面执行 |
| 拖到回收站后文件"看起来"还在 | 回收站视图未刷新 | 刷新回收站再确认 |
| 首次点击托盘菜单偶发不弹 | 已知 churn 风险（P1 残留） | 记录复现步骤，不阻塞 |
