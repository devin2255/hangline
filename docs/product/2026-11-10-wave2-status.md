## 1. 范围与非目标

**做（Wave 2 全部）**：让线上的截图「可找回、可解释」——备注/标签元数据、一个按需唤起/关闭即销毁的搜索窗、四处搜索入口、停悬大图预览，以及 OCR 文本索引 PoC。它是产品护城河（晾衣绳的空间化留存）从「看得见」走向「找得回」的一步。

**不做（本轮一行不碰）**：

- **不做常驻/复用窗口**：搜索窗是唯一新增可视面，且**打开创建、关闭销毁**；不新增第二个常驻窗口（Pin/命令面板/HUD 仍在 Wave 3 评估）。
- **不做云端/账号/同步/遥测**：OCR 与索引全部本地；「唯一网络请求 = 更新检查」不变（见 spec §9 Amendment 2026-11-10 / 2026-11-10b）。
- **不做富文本**：备注/标签纯文本，不渲染 Markdown/HTML（防注入，也避免检索语义复杂化）。
- **不做多选/批量导出**（原 W2.5）：与 OLE 拖出手势、以及「搜索窗按需生命周期」的验证优先级冲突，顺延后续批次；`Ctrl` 点选仍不做框选。
- **不做移动端/跨平台**、不改面板窗口尺寸与定位。
- **版本号 bump / CHANGELOG 转正**：Wave 2 验收前不做（避免「v1.3 名不副实」）。

## 3. 关键设计决策

| # | 决策 | 理由 | 影响 |
|---|---|---|---|
| **D1** | 搜索窗**按需创建、关闭即销毁**，不隐藏复用 | 新增 WebView2 可视面按 +70–135 MB/窗口计（spec §9 Amendment 2026-11-10）；只有「打开期间计入峰值」才能既给检索能力、又不破常驻内存预算 | 验收必须测「打开→关闭→回落」三段数据；若销毁后内存不回落，本决策视为失败（见 R1） |
| **D2** | 面板窗口**不承担搜索输入**；搜索与备注/标签编辑都在可聚焦搜索窗内 | 面板 `focusable:false` 是「绝不抢焦点」红线，无法收键盘；搜索窗是**显式声明的编辑器类例外**，与标注/裁剪窗同类管理 | 用户主动触发才创建并聚焦；关闭后焦点回原窗口 |
| **D3** | 备注/标签**只做纯文本**，不渲染富文本 | 防注入（备注/标签/文件名/路径都是不可信输入）；也避免「检索语义 + 富文本」双复杂度 | 渲染层不得插入 HTML；如做查询高亮，只能拼接文本节点 |
| **D4** | 搜索是**前端本地过滤**，不新增后端搜索命令/索引 | 线上条目上限 100（25/50/100），本地过滤足够快；少一条 IPC 与一整套索引写路径 | 数据源为 `AppState` 全量 items（可能多于线上显示的 N 张），UI 需如实呈现结果数量；条目量增长后另评估索引 |
| **D5** | 四处入口共用**同一个幂等 `open_search`** | 避免多实例与重复建进程；托盘/热键/面板菜单/改键窗行为一致 | 任一处失败都以同一可诊断错误呈现 |

## 5. 风险与待裁决项

| # | 风险 | 具体机制 | 缓解 / 裁决需求 |
|---|---|---|---|
| **R1** | **关闭搜索窗后内存不回落**（按需生命周期失败） | WebView2 窗口销毁后 Chromium 子进程可能延迟退出或残留；若 3 次开/关后进程树私有内存递增，D1 的核心前提破产 | 关窗后等待 ≥10 s 再采样；必要时显式释放 webview/进程；验收按「关闭后 ±30 MB + 3 次不递增」硬判。**若达不到：不上线搜索窗，或回退「预热复用」需重新评审并回写 spec Amendment**——不能两者兼得 |
| **R2** | **OCR 精度不达门槛**（W2.5 最大的沉没成本风险） | 系统 OCR 对中文界面截图的召回取决于语言包是否安装、字号/对比度/艺术字；80% 关键词召回可能达不到 | 先做 PoC 再决定是否产品化：评测集 = **≥30 张可复现合成中文截图**（协议见 [W2 OCR 评测协议](../acceptance/W2-ocr-eval.md)），**不达标就不上线**（spec 硬约束）；若目标机缺 zh-Hans OCR 组件，需降级提示而不是静默空结果 |
| **R3** | **纯文本输入的注入/渲染风险** | 备注、标签、文件名、路径均为不可信输入；若未来做「查询高亮」或标签 chips 误用 `dangerouslySetInnerHTML`，就是 XSS 面 | D3 硬约束；渲染一律 React 文本节点；如做高亮只拼文本片段；不引入 Markdown；真机回归加一条「输入 `<img src=x onerror=…>` 不执行」的检查 |
| **R4** | **数据源与保留语义不一致** | 搜索基于 `AppState` 全量 items：默认 `fit` 模式是**视图策略**、state 无上限，搜索结果可能多于线上可见的 ≤12 张；25/50/100 模式下 state 被裁剪到对应上限 | UI 如实显示「N 条结果」并标注来源；先按全量搜；若 `fit` 用户条目量显著增长（>1000）再评估索引/分页，**本轮不引入** |
| **R5** | 搜索窗是「抢焦点」的显式例外 | 可聚焦窗口与「绝不抢焦点」红线的张力 | 仅**用户主动触发**时创建并聚焦（热键/托盘/菜单），绝不自动弹出；关闭后焦点回原窗口；启动不预创建 |
| **R6** | 第四热键冲突 | `Ctrl+Alt+F` 与浏览器/IDE/输入法可能冲突；冲突处理不当会让用户误以为功能坏了 | 复用现有冲突检测/回滚/托盘提示；改键小窗支持 `target=search`；验收含「先占用 `Ctrl+Alt+F` 再启动」用例 |

### 9.2 批次 2 验收口径（摘要，详见 §2 任务板）

**W2.4 停悬预览**

- **300 ms** 停悬出现；移开/滚动/拖动/打开菜单或胶囊立即收起；菜单打开期间必须隐藏（不能盖住菜单）。

- 几何：最大高度 = 面板高 − 16 dp；宽按原图比例、上限 520 dp；底部对齐面板下沿；水平居中于停悬卡片并 clamp 在面板内。
- 60fps 不破（12 卡）；`prefers-reduced-motion: reduce` 时无过渡；大图失败/录像回退缩略图或不显示。

**W2.5 OCR**

- 只用系统 `Windows.Media.Ocr`；**0 字节安装增量**；离线；不联网。
- 索引：`%LOCALAPPDATA%\Hangline\ocr-index.json`，格式 `{version, language, entries: {"<itemId>": {hash, text, indexedAt}}}`；原子写；坏文件当空 + 告警；**可删除重建**（删除后搜索降级为备注/标签）。
- 构建：单飞（并发调用只跑一个）+ worker 线程 + 逐张失败不中断 + 日志可诊断。
- 探针：`hangline.exe --ocr-probe <dir>` 逐图输出 JSON line（`file/ok/text/lines/ms`）+ summary（`files/ok/failed`）；**退出码 = 失败文件数（上限 1）**。
- **接入搜索 UI 的唯一条件**：评测集（≥30 张可复现合成中文截图）**关键词召回率 ≥ 80%**；不达标保持 PoC、不接入 UI。

### 9.3 内存口径（批次 2）

- **W2.4 预览不新增窗口 → 常驻进程树私有内存不应上升**；验收记录「开预览前 / 开预览中」两次读数（预期变化在测量噪声内，不设新窗口额度）。
- **W2.5 索引常驻只是一个 JSON 文件**：体积随条目数线性增长，需真机记录文件大小，并随条目删除/年龄清理同步失效；**OCR 引擎是 Windows 系统组件**，识别为瞬时内存、不计入常驻，也不增加安装体积（spec §9 Amendment 2026-11-10b）。
- 「常驻不升」以 **247.9 MB**（干净进程树口径，2026-11-10 复测）为**相对基线**。
- **裁决（2026-11-10，lead）**：内存数字统一采用**干净进程树口径**（WMI `ParentProcessId` 子树，排除本机其它应用的 WebView2 进程）。批次 1 的常驻基线为 **247.9 MB**；早前的 406.2 MB 是受污染读数，作废。spec §9 的 **≤350 MB（暂定）** 绝对阈值**维持不变**，当前常驻 247.9 MB、开窗峰值 284.4 MB 均在阈值内；+70–135 MB/可视面的预算也未被打破（搜索窗 +36.5 MB，关闭后 +4.3 MB）。后续批次沿用同一测量脚本 `.acceptance/harness/phase-w2-memory.ps1`（git-ignored）。

### 9.4 批次 2 风险与残余

- **OCR 精度**：评测不达标是大概率分支；评测结果决定「接入 UI」还是「保持 PoC」——两条都是可交付结论，不算失败。
- **语言包依赖**：目标机若缺 zh-Hans OCR 组件，`availability()` 必须给出可诊断提示，搜索窗不得静默空结果。
- **索引增长**：`fit` 模式下 items 无上限，索引文本随条目累积；PoC 阶段以真机记录文件体积，产品化前需定上限（如按条目数/总字节裁剪）。
- **预览遮挡**：预览浮层虽 `pointer-events:none`，仍需真机确认不遮挡菜单/胶囊点击与拖拽起点。
