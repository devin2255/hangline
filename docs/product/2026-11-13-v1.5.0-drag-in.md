## 1. 实现摘要

| 层 | 内容 |
|---|---|
| OLE 投放 | 面板 `disable_drag_drop_handler()` + 自建手写 `IDropTarget`（顶层 HWND + 全部 WebView2 子 HWND，6 个）；支持 `CF_HDROP` / `"PNG"` / `CF_DIBV5` / `CF_DIB`，OLE 回调只做有界原始数据提取（≤64 MB），解码/落盘在 worker 线程 |
| 入库 | RGBA → PNG → `Screenshots\Dropped yyyy-MM-dd HH.mm.ss.png`（原子写）→ BLAKE3-64 去重（LRU + 线上已有卡片 hash，跨重启）→ 缩略图 → `AppState::add_item(ItemKind::Dropped)` → state 广播 |
| 门控 | 36 ms 轮询、按下 + 位移 ≥4 px 才视为外部拖拽；面板 window 上方 12 px 容差内 `hittest::set_drag_hold(true)` 临时让位点击穿透；内部拖出期间完全让位 |
| 唤出 | 拖拽进入工作区顶部 14 dp 唤出带 → `Command::DropReveal` / `RevealReason::Drop`；不 pin、不抢焦点、在指针所在显示器唤出；拖拽期间 `reveal::set_drop_hold(true)` 暂停收起 |
| 前端 | `dropin-hover/leave/result` 事件 → 绳子高亮 + "松手挂上绳子" + 2 s 结果轻提示；`RevealReason` 增加 `drop`；右键菜单对 `dropped` 支持回收站 |
| 边界 | 单次 ≤20 张、≤64 MB payload、单图 ≤80 MP；视频/其它文件拒绝；无新窗口、无新网络请求 |
