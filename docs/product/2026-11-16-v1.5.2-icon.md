## 1. 设计方向

保留 Hangline 的核心识别符——**照片被晾在绳子上**——重新绘制：

| 元素 | 处理 |
|---|---|
| 底 | 深墨绿丝光渐变（#1A2730 → #090D11），顶部一层很淡的青色光晕 |
| 绳 | 暖金「真丝」质感，自然下垂，两端黄铜绳帽 + 细高光 |
| 衣夹 | 黄铜渐变、深色描边、弹簧细节，轻微倾斜夹住卡片 |
| 卡片 | 奶油白拍立得，落日山景缩略图 + 两条说明线，轻微旋转与真实投影 |
| 尺寸 | 16 / 32 px 下仍需辨认：卡片轮廓、绳线、衣夹三者保持对比 |

候选方案：
- **A · Lumen（采用）**：深色丝光，和 App 深色玻璃面板、四种绳子材质最一致；
- B · Atelier：暖纸日光，更轻更文具，浅色桌面上更跳；
- C · Medallion：圆形徽章，轮廓最独特，但会打破 Windows 圆角方形体系。

## 2. 资产与可复现来源

- **源图**：`src-tauri/app-icon.png`（1024×1024，透明圆角外框）
- **渲染脚本**：`scripts/design/app-icon.py`（Python + Pillow + numpy；仅在需要改标时本地运行，构建不依赖）
- **生成命令**：`pnpm tauri icon src-tauri/app-icon.png`
- **产物**：
  - Windows：`src-tauri/icons/icon.ico`（16/24/32/48/64/256）、`32x32.png`、`64x64.png`、`128x128.png`、`128x128@2x.png`
  - macOS：`src-tauri/icons/icon.icns`
  - Microsoft Store：`Square*Logo.png`、`StoreLogo.png`
  - 托盘：Tauri 托盘默认使用应用图标（`icons` 配置未单独覆盖）
  - 安装器/便携版：`Hangline.ico` 由 `build-release.mjs` 从 `icons/icon.ico` 同步
  - press kit：`docs/press/hangline-logo.png`（512×512，由新 `icon.png` 缩放）
