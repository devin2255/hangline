## 1. 闸门（不达标不上线）

| 项 | 规则 |
|---|---|
| 通过线 | **中文关键词召回率 ≥ 80.0%**（按 §3 的定义与 §2 的评测集） |
| 附加条件 | `--ocr-probe` 运行 `failed = 0`（无 OCR 失败文件）；缺一不可 |
| 通过后 | 允许在搜索窗增加「含图片文字」结果区（或对命中项加「图片含此文字」标注）；接入任务另行排期 |
| 不通过 | **本次不接入搜索 UI**；在本文件记录差距（召回率、失败样本、耗时）与改进方向（缩放/语言包/预处理/字体渲染），保留 PoC 结论 |
| 不允许 | 用「部分图片命中」「目测可以」替代阈值；不达标就不能写「已接入」 |

## 2. 评测集构造（无人工标注成本、可复现）

**原则**：不用真实用户截图（隐私 + 不可复现），用**程序合成**的中文界面截图；每张图的「正确答案」在生成时就固定，因此不需要人工标注。

| 项 | 规格 |
|---|---|
| 数量 | **≥ 30 张**（建议 30–40 张；每张独立） |
| 尺寸 | 1280×800（16:10，接近常见窗口截图） |
| 内容 | 每张 **3–5 个可复现中文短语**，另混入 UI 元素（标题栏、按钮、输入框边框、标签页、浅色/深色背景、分隔线）以模拟真实界面纹理 |
| 字体 | Microsoft YaHei（UI 常用字体）；字号分级：标题 24–28 px、正文 14–16 px、说明 11–12 px |
| 布局 | 固定随机种子（如 `seed=20261110`）决定短语位置/色值/间距；同一 seed 生成结果字节级可复现 |
| 短语库 | 至少 40 条中文短语，例如：`登录失败：密码错误` / `导出报表已生成` / `月度销售汇总` / `订单已提交` / `网络连接超时` / `请检查输入内容` / `已保存到草稿箱` / `审批流程已通过` / `文件上传完成` / `暂无更多数据` |
| 难度分布 | 30 张中至少 10 张包含小字号（11–12 px）正文、至少 5 张包含低对比度（浅灰字/浅背景）短语——这两类最接近真实低召回场景 |
| 正确答案 | 生成时输出 `keywords.json`：`{ "<filename>": ["短语1", "短语2", ...] }`（与图片同目录） |

**目录约定**（本地、git-ignored，不入库）：

```
.acceptance/ocr-eval/
├── fixtures/                 # 30+ 张 1280x800 PNG
│   ├── ocr-001.png …
├── keywords.json             # { "ocr-001.png": ["登录失败：密码错误", …], … }
├── gen-fixtures.ps1          # 生成脚本（.NET System.Drawing；固定 seed；记录版本）
└── probe.jsonl               # --ocr-probe 输出（逐行 JSON）
```

生成脚本要求：用 PowerShell + `System.Drawing.Common`（Windows 自带 .NET），不引入新依赖；脚本必须写入同一 `keywords.json`；脚本本身不入库（`.acceptance/` 已在 `.gitignore`），但**生成参数（seed / 短语库 / 字号）必须记录在本文件 §7**，任何人可据此复现。

## 3. 指标定义

**归一化**（对 OCR 文本与关键词同时执行，保证口径稳定）：

1. 去除所有空白字符（空格、换行、制表符、全角空格）——中文 UI 的 OCR 常在字符间或多行处产生空格；
2. 拉丁字母大小写折叠（中文不受影响）；
3. 标点保留（`：` `，` `。` 等按原字符参与匹配）。

**命中（Hit）**：一个关键词在归一化后的 OCR 文本中作为**连续子串**出现，即算命中（不做模糊匹配、不要求词序之外的语义）。

**指标**：

| 指标 | 公式 / 采集方式 |
|---|---|
| 关键词召回率（主指标） | `命中关键词数 / 总关键词数 × 100%`；**≥ 80.0% 为通过** |
| 单图平均耗时 | `--ocr-probe` 每条 JSON 的 `ms` 字段求平均（含解码+识别） |
| 失败文件数 | probe 输出 `failed`；**必须为 0** |
| 精确率粗估（可选） | 人工抽查 10 张图的 OCR 文本，记录「误识别出的明显错误短语数」；仅作参考，不作闸门 |
| 重复关键词 | 同一短语出现在多张图时逐张逐条计数（不合并），避免少样本被放大 |

**统计口径**：以**关键词**为计数单位（不是以图片为单位）；测试集总关键词数应 ≥ 100 条（30 张 × 3–5 条）以保证 80% 的统计意义。

## 4. 执行方式

前置：Windows 10 22H2 / Windows 11；系统已安装 **zh-Hans OCR 语言组件**（`Windows.Media.Ocr` 的语言包）；release 构建可用。

```powershell
# 1) 构建 release（无需安装包）
pnpm tauri build --no-bundle
# 产物：src-tauri\target\release\hangline.exe

# 2) 生成评测集（本地脚本，固定 seed）
pwsh .acceptance\ocr-eval\gen-fixtures.ps1

# 3) 运行 OCR 探针（不启动 GUI；逐图输出 JSON line，最后输出 summary）
$exe = "src-tauri\target\release\hangline.exe"
& $exe --ocr-probe .acceptance\ocr-eval\fixtures > .acceptance\ocr-eval\probe.jsonl 2>&1
# 退出码 = 失败文件数（上限 1）；$LASTEXITCODE 为 0 才进入打分

# 4) 打分（读取 keywords.json + probe.jsonl，按 §3 归一化与子串命中）
#    脚本在 .acceptance/ocr-eval/score-ocr.ps1；输出：总关键词/命中/召回率/平均耗时
```

**探针输出契约**（由 `--ocr-probe` 保证；后端实现见 Wave 2 状态看板 §9.2）：

- 每张图一行 JSON：`{"file":"...","ok":true,"text":"...","lines":N,"ms":123}`；失败为 `{"file":"...","ok":false,"error":"..."}`
- 最后一行 summary：`{"files":N,"ok":N,"failed":N}`
- 退出码 = 失败文件数（上限 1）

> 生成与打分脚本都落在 `.acceptance/ocr-eval/`（git-ignored、**不入库**）；口径以本文件 §2–§3 为准，任何人可按此重写脚本复现。评测只把汇总数字填进 §5，不把 OCR 全文提交到任何外部系统。

## 6. 判定后的分支

**通过（召回率 ≥ 80% 且失败 0）**
1. 记录本文件结果表；在 [Wave 2 状态看板](../product/2026-11-10-wave2-status.md) §9 更新闸门状态为「已通过」。
2. 排期接入搜索 UI：搜索窗增加「含图片文字」结果区（或对命中项加标注）；命中项仍需**纯文本渲染**（不插入 HTML），excerpt 展示命中上下文。
3. 索引与 UI 接入后重跑一次本协议（回归），避免接入改动影响召回。

**不通过（< 80% 或存在失败文件）**
1. 记录差距：召回率、失败样本清单、最差字号/对比度分布。
2. 记录改进方向并逐项验证（下一轮重跑）：图像预处理（放大/二值化/对比度）、OCR 前缩放上限（当前实现最长边 ≤ 2560 px）、语言包确认、字号/字体调整。
3. **本轮不接入搜索 UI**；搜索保持「文件名/备注/标签/路径」四类命中。PoC 结论本身可交付（明确「为何不上」也是结论）。

## 7. 复现参数与隐私边界

**复现参数（生成脚本必须固定并记录）**

| 参数 | 值 |
|---|---|
| 随机种子 | `20261110`（固定；如变更需在本表注明） |
| 画布尺寸 | 1280×800 |
| 字体 | Microsoft YaHei |
| 字号档位 | 24–28 / 14–16 / 11–12 px |
| 每图短语数 | 3–5 |
| 图片格式 | PNG（8-bit，无透明） |
| 短语库版本 | v1（≥40 条，见 §2 示例） |

**隐私与数据边界**

- 评测集全部为**程序合成**内容，不含任何真实用户截图或个人信息；生成脚本与图片保存在 `.acceptance/`（git-ignored），不进仓库、不进安装包。
- OCR 全部在**本机**完成（`Windows.Media.Ocr` 系统组件）；**0 字节安装增量**，不下载模型、不联网。
- 索引文件：`%LOCALAPPDATA%\Hangline\ocr-index.json`（`{version, language, entries: {"<itemId>": {hash, text, indexedAt}}}`），**纯本地 JSON、可删除重建**；删除后搜索降级为仅备注/标签命中；索引不参与任何联网请求。
- **「唯一网络请求 = 更新检查」不因 OCR/索引改变**（见 spec §9 Amendment 2026-11-10b）。
- 评测日志/结果只记录文件名、召回数字与耗时，不把整段 OCR 文本提交到任何外部系统；本文件只填汇总数字。
